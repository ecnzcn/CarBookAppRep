# Changelog

All notable changes to CarBook are documented here. Format loosely follows
[Keep a Changelog](https://keepachangelog.com/); versions follow
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-02

- Deutsche Benutzeroberfläche (gesamte App auf Deutsch übersetzt)
- Vollständiges Fahrtenbuch: Fahrzeuge, Wartung, Probleme, Tankungen, Reifen,
  Dokumente, Erinnerungen
- Timeline (chronologische Fahrzeughistorie), Kostenübersicht mit
  Jahres-Aufschlüsselung, Suche & Filter
- Backup-Export/-Import als ZIP (`CarBook-Backup-YYYY-MM-DD.zip`)
- Installierbare PWA mit Offline-Unterstützung, veröffentlicht über GitHub
  Pages
- In-App-Versionsanzeige mit Änderungsprotokoll (Einstellungen)

## [0.1.0] - 2026-09-16

- Erste Version: Projekt-Grundgerüst (Vite + React + TypeScript + Dexie),
  Fahrzeugprofil (Anlegen/Bearbeiten/Löschen), Dashboard, PWA-Grundgerüst
  (Manifest, Service Worker)
